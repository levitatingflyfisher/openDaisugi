the recipe

How a board is made

A report first.Deep research with three-vote verification, committed under docs/research. The board cites it and never goes past it.
Archive every screen.sources.json names each image and where it came from. fetch.py downloads, verifies, shrinks, and writes the fetch date. The repo is the record, so a vanished source does not take the board with it.
Tag with the report's verdict.Steal, avoid, competitor, unverified, reference. verdicts.json holds the rule, the card shows the reason.
Draw ours from real screens.Part three starts from the CLI as it runs today, then says what should change, and names the plan that changes it.
Three examples per plugin kind.No kind exists in the spec until three examples run against it. Views, policies, adapters, backends, state sources, bridges, notifiers.

Screens in part one of each board belong to their makers and are archived for study. Everything in part three is original work for openDaisugi. To rebuild after editing a body.html, run _shell/render.py.
