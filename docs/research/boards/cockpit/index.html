part two

What holds

Six of the ten laws from the cockpit research of 2026-08-27. The other four moved to the gate and gateway boards.

Roster first, transcript second.The default screen lists agents by what you must do, needs input on top. This was the fix for "it felt like a settings page".
The transcript is an append-only tree.Every entry has an id and a parent id. Rewind moves the head. Fork copies the path. Nothing is deleted.
Rewind has two axes.Conversation and workspace restore independently, and the screen says which one did not.
Keys on screen, generated from the bindings.zellij's footer, lazygit's panel hints, k9s's header. The ramp is printed, never memorized.
Redraw on events, diffed in place.No timer repaint, no reflow under the eye. htop's discipline.
Alerts by class, honesty by glyph.Most verdicts scroll. A curated class pauses and zooms. Stale numbers dim, estimates carry a question mark, dead controls are labelled.

today

The map that admits what is not wired.

Three glyphs, three truths. The dashboard puts live gauges on the same boxes. This is the infant tier and it stays.

should be

The roster moves to the floor. The rules come with it.

  • The sessions view is the coppice roster now. One shape in terminal and browser, from the floor board. The cockpit stops being a second place to look.
  • Tree and garden become view plugins over the floor's socket, in the same rail as kanban and colony.
  • Wiring becomes a command, reachable, not the default screen.
  • The tree store stays as specified: one append-only JSONL per session with ids, parents, verdicts, checkpoints, and a head.
